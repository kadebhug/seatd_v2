# Seatd Logo Kit

Production logo and launcher assets for Seatd.

Start with [`DESIGN.md`](./DESIGN.md) for usage rules and the platform asset map. The `core/` directory contains the authoritative vector masters. Platform folders contain generated delivery formats.

## Contents

- `core/` — colour, reverse, and monochrome SVG masters
- `web/` — favicon, PWA, maskable, Apple touch, and Open Graph assets
- `flutter/` — shared source plus Android, iOS, Windows, macOS, and Linux assets
- `surfaces/` — role-labelled launch screens for product surfaces
- `tokens/` — machine-readable design tokens
- `preview/` — visual kit overview

Do not create separate logos for Owner, Waiter, Display, Guest Assist, or Platform Admin. They are product contexts under one Seatd identity.
