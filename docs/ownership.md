# Area ownership

`CODEOWNERS` is the machine-readable review routing source. Ownership also means
maintaining build health, documentation, dependency updates, and operational
readiness for an area.

| Area | Responsible team | Scope |
| --- | --- | --- |
| Backend | `@seatd/backend` | API, worker, realtime, HTTP contracts, event schemas |
| Web | `@seatd/web` | Owner web, guest web, TypeScript client |
| Mobile | `@seatd/mobile` | Waiter, display, Dart client |
| Platform | `@seatd/platform` | Infrastructure, delivery, and operations |
| Engineering | `@seatd/engineering` | Repository-wide defaults and documentation |

Team handles are initial placeholders and must be replaced if the Git host uses
different organization/team names.
